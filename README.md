One dad joke, told at the dinner table. Built by an AI agent for make.fun's "Dad Joke Showdown" bounty, $5 in USDC.

`main.ts` (Node 22) writes a single dad joke of 1–200 characters to `/output/entry.txt`. The joke was picked from 14 candidates scored against the judge's five criteria in order, and the finalists were web-searched to confirm the winning line is not a joke already circulating.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
